# 📌 Overview

This repository contains my **hands-on Red Team practical labs** performed in a controlled lab environment.

The objective of these projects is to simulate real-world offensive security techniques used by penetration testers and Red Team operators while documenting every step professionally.

The repository covers web application attacks, Active Directory exploitation, privilege escalation, malware analysis, password attacks, API security, network penetration testing, and much more.

---

# 🎯 Objectives

- Perform practical Red Team exercises
- Learn offensive security methodologies
- Simulate enterprise attack scenarios
- Improve penetration testing skills
- Document every lab professionally
- Build a public cybersecurity portfolio
