# Admin Panel Discovery Testing



## Lab Environment



## Target Application:

OWASP Juice Shop



## Testing Type: 

Web Application Penetration Testing





## Tools Used

- Burp Suite Community Edition
- Browser Developer Tools
- OWASP Juice Shop
- Kali Linux





---



## Objective



To discover hidden administrative functionality and identify exposed admin-related endpoints.





---



## Testing Method



The following methods were used:



- Reviewed application routes.
- Analyzed Burp Suite HTTP History.
- Observed API endpoints requested by the application.
- Checked hidden paths and administrative resources.





---



## Testing Steps



1. Logged into the application.
2. Opened Burp Suite.
3. Monitored HTTP requests generated by the application.
4. Analyzed discovered endpoints related to administrative functions.





---



## Discovered Paths



- Possible administrative routes:

/#/administration
/rest/admin




---



## Discovered Endpoint



- The following admin-related endpoint was identified:


GET /rest/admin/application-version



---


## Observation

- Administrative API endpoints were exposed.
- Application contained separate routes for administrative functionality.
- Access control testing is required to verify whether unauthorized users can access these resources.



---




## Security Analysis



- Exposed administrative endpoints may increase the attack surface of a web application.
- Proper authorization checks should be implemented on all administrative functions.
